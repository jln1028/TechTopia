TechTopia Intro Lessons

Take these five interactive lessons in order.

  1. Using Your pi-top [4]Power on, desktop, file manager, settings, Foundation & Expansion Plate.
  2. Introduction to the TerminalPrompt, navigation, files and folders, shortcuts.
  3. Pac-Man Terminal Treasure HuntPractise terminal commands, hidden files and wildcards.
  4. Intro to PythonVariables, input, decisions, loops, lists, functions, a guessing game.
  5. Sense HAT Interactive LabText, images, orientation, sensors, movement, a reaction game. Uses sense_hat.
