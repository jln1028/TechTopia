# Part 2: Physical Computing Materials

Classroom materials for the TechTopia Industry Challenge. This part bridges what students learned with the Sense HAT in Part 1 into physical computing with external components, using the `pitop` SDK.

Start from [`index.html`](index.html), or open any page directly in a browser.

## Contents

| Folder | What is inside |

| [`01_Curriculum_Websites/`](01_Curriculum_Websites/) | [Physical Computing Hub](01_Curriculum_Websites/TechTopia_Physical_Computing_Hub.html), which includes the coding constructs |
| [`02_Student_Assessment/`](02_Student_Assessment/) | [20-question physical computing quiz](02_Student_Assessment/TechTopia_20_Question_Quiz.html) and [Sense HAT quiz](02_Student_Assessment/TechTopia_sense_hat_quiz.html) |

## How to use

Open the HTML files in a browser. No build step or internet connection is needed for the pages themselves. This has been confirmed with the repository cloned locally onto a pi-top.

## Important notes

- The pages use icon and text styling only. They do **not** include embedded pi-top hardware photos or TechTopia background images.
- The Python examples were carried forward from the class materials. The code has been run on pi-top hardware by the maintainer. Before classroom use, still validate the SDK component names, port compatibility and sensor reading ranges on your own pi-top [4] hardware.
