Team 1: Smart Security System

Project purpose: A button arms or disarms the system. When armed, the system watches the light sensor and sound sensor. If it gets dark or noisy, it triggers an alarm with an LED and buzzer.

ThemeSecurity
Visitor InteractionPress the button to arm the system, then clap or cover the light sensor to trigger the alarm.
GoalWorking interactive demo for the semester showcase

Wiring Guide

  • LED → D2
  • Buzzer → D0
  • Button → D5
  • Light Sensor → A1
  • Sound Sensor → A2

from pitop import Button, LED, LightSensor, SoundSensor, Buzzer
from time import sleep

button = Button("D5")
led = LED("D2")
light = LightSensor("A1")
sound = SoundSensor("A2")
buzzer = Buzzer("D0")

armed = False
LIGHT_THRESHOLD = 400
SOUND_THRESHOLD = 600

while True:
    button.wait_for_press()
    armed = not armed

    if armed:
        led.on()
    else:
        led.off()

    while armed:
        light_level = light.reading
        sound_level = sound.reading

        print("Light:", light_level, "Sound:", sound_level)

        if light_level < LIGHT_THRESHOLD or sound_level > SOUND_THRESHOLD:
            print("ALARM!")
            buzzer.beep(on_time=0.1, off_time=0.1, n=5)

        if button.is_pressed:
            armed = False
            led.off()

        sleep(0.2)

Finished Working Code

Use this final version only after your team has tested the smaller code snippets above.

from pitop import Button, LED, LightSensor, SoundSensor, Buzzer
from time import sleep

button = Button("D5")
led = LED("D2")
light = LightSensor("A1")
sound = SoundSensor("A2")
buzzer = Buzzer("D0")

armed = False
LIGHT_THRESHOLD = 400
SOUND_THRESHOLD = 600

print("Smart Security System Ready")
print("Press the button to arm or disarm")

while True:
    if button.is_pressed:
        armed = not armed

        if armed:
            led.on()
            print("System ARMED")
        else:
            led.off()
            print("System DISARMED")

        sleep(0.4)

    if armed:
        light_level = light.reading
        sound_level = sound.reading

        print("Light:", light_level, "Sound:", sound_level)

        if light_level < LIGHT_THRESHOLD or sound_level > SOUND_THRESHOLD:
            print("ALARM TRIGGERED")
            for _ in range(3):
                led.on()
                buzzer.on()
                sleep(0.15)
                led.off()
                buzzer.off()
                sleep(0.15)

    sleep(0.1)
