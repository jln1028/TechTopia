Team 2: TechTopia Reaction Challenge

Project purpose: Visitors play a reaction game. The potentiometer sets difficulty, the LED signals when to react, the button records reaction time, and the sound sensor can detect a false start.

ThemeGame
Visitor InteractionTurn the knob to choose difficulty, wait for the light, then press the button as fast as possible.
GoalWorking interactive demo for the semester showcase

Wiring Guide

  • LED → D2
  • Buzzer → D0
  • Button → D5
  • Potentiometer → A3
  • Sound Sensor → A2

Finished Working Code

Use this final version only after your team has tested the smaller code snippets above.

from pitop import LED, Button, Buzzer, Potentiometer, SoundSensor
from time import sleep, time
import random

led = LED("D2")
button = Button("D5")
buzzer = Buzzer("D0")
knob = Potentiometer("A3")
sound = SoundSensor("A2")

SOUND_THRESHOLD = 650
best_time = None

print("TechTopia Reaction Challenge")
print("Turn the knob to choose difficulty")
print("Wait for the light, then press the button")

while True:
    value = knob.position

    if value < 333:
        level = "Easy"
        min_wait = 3
        max_wait = 5
    elif value < 666:
        level = "Medium"
        min_wait = 2
        max_wait = 4
    else:
        level = "Hard"
        min_wait = 1
        max_wait = 3

    print("Difficulty:", level)
    print("Get ready...")
    sleep(1)

    wait_time = random.uniform(min_wait, max_wait)
    start_wait = time()
    false_start = False

    while time() - start_wait < wait_time:
        if sound.reading > SOUND_THRESHOLD:
            false_start = True
            break
        sleep(0.05)

    if false_start:
        print("False start! Too much noise too early.")
        buzzer.on()
        sleep(0.5)
        buzzer.off()
        sleep(1)
        continue

    led.on()
    start = time()
    button.wait_for_press()
    reaction = time() - start
    led.off()

    print(f"Reaction time: {reaction:.3f} seconds")

    if best_time is None or reaction < best_time:
        best_time = reaction
        print(f"New best time: {best_time:.3f} seconds")

    buzzer.beep(on_time=0.08, off_time=0.05, n=2)
    sleep(2)
