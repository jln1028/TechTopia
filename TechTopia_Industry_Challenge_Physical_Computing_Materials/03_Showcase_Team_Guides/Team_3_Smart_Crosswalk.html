🚦 Smart City Showcase Team Guide

Team 3: Smart Crosswalk / Safe City Demo

Project purpose: A visitor presses a button to request crossing. The system behaves like a traffic light. It also uses the light sensor for day/night mode and the sound sensor to change the crossing behavior.

ThemeSmart City
Visitor InteractionPress the crossing button and watch how light and sound conditions change the traffic system.
GoalWorking interactive demo for the semester showcase

Wiring Guide

  • Red LED → D1
  • Yellow LED → D2
  • Green LED → D3
  • Button → D5
  • Light Sensor → A1
  • Sound Sensor → A2
  • Buzzer → D0

Finished Working Code

Use this final version only after your team has tested the smaller code snippets above.

from pitop import LED, Button, Buzzer, LightSensor, SoundSensor
from time import sleep

red = LED("D1")
yellow = LED("D2")
green = LED("D3")
button = Button("D5")
buzzer = Buzzer("D0")
light = LightSensor("A1")
sound = SoundSensor("A2")

LIGHT_THRESHOLD = 400
SOUND_THRESHOLD = 650

def set_lights(r, y, g):
    if r:
        red.on()
    else:
        red.off()

    if y:
        yellow.on()
    else:
        yellow.off()

    if g:
        green.on()
    else:
        green.off()

print("Smart Crosswalk Demo Ready")
set_lights(False, False, True)

while True:
    if button.is_pressed:
        print("Crossing requested")

        light_level = light.reading
        sound_level = sound.reading

        print("Light:", light_level, "Sound:", sound_level)

        if light_level < LIGHT_THRESHOLD:
            crossing_time = 5
            print("Night mode: longer crossing time")
        else:
            crossing_time = 3
            print("Day mode: normal crossing time")

        if sound_level > SOUND_THRESHOLD:
            print("Heavy noise detected: delaying crossing")
            sleep(2)

        set_lights(False, True, False)
        sleep(1)

        set_lights(True, False, False)

        for _ in range(crossing_time * 2):
            buzzer.on()
            sleep(0.1)
            buzzer.off()
            sleep(0.4)

        set_lights(False, False, True)
        sleep(0.5)

    sleep(0.1)
