# Challenge materials

Curriculum, assessment and build guides for the Physical Computing showcase. These use the `pitop` SDK (LED, Button, Buzzer, LightSensor, SoundSensor, Potentiometer), except the Sense HAT quiz.

## Curriculum

- [Physical Computing Hub](../TechTopia_Industry_Challenge_Physical_Computing_Materials/01_Curriculum_Websites/TechTopia_Physical_Computing_Hub.html): concepts, project library, coding constructs, glossary, teacher note.

## Assessment

- [Physical Computing Quiz](../TechTopia_Industry_Challenge_Physical_Computing_Materials/02_Student_Assessment/TechTopia_20_Question_Quiz.html): 20 questions.
- [Getting Started with the Sense HAT](../TechTopia_Industry_Challenge_Physical_Computing_Materials/02_Student_Assessment/TechTopia_sense_hat_quiz.html): interactive quiz.

## Showcase team guides

Each guide has a wiring guide, team roles, build checklist, build steps, finished code and presentation reminders.

- [Team 1: Smart Security System](../TechTopia_Industry_Challenge_Physical_Computing_Materials/03_Showcase_Team_Guides/Team_1_Smart_Security_System.html)
- [Team 2: Reaction Challenge](../TechTopia_Industry_Challenge_Physical_Computing_Materials/03_Showcase_Team_Guides/Team_2_Reaction_Challenge.html)
- [Team 3: Smart Crosswalk / Safe City Demo](../TechTopia_Industry_Challenge_Physical_Computing_Materials/03_Showcase_Team_Guides/Team_3_Smart_Crosswalk.html)
